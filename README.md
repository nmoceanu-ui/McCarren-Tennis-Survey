# McCarren Tennis Survey

Campaign site for public tennis courts on the McCarren Park asphalt lot, with the community survey and a live response counter. Static site: `index.html` plus `img/`, `models/` and `counter.js`. Hosted on GitHub Pages (or Netlify; see DEPLOY.md). The counter reads aggregate counts only from a Google Apps Script endpoint (`Code.gs`); no respondent data is in this repository.
